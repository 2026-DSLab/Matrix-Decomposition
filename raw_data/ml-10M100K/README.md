### 파일 구성

| 파일 | 설명 | 구분자 | 컬럼 |
|---|---|---|---|
| `ratings.dat` | 평점 기록 | `::` | `userId::movieId::rating::timestamp` |
| `movies.dat` | 영화 메타데이터 | `::` | `movieId::title::genres` |
| `tags.dat` | 유저 태그 기록 | `::` | `userId::movieId::tag::timestamp` |

- `rating`: 0.5 ~ 5.0 사이 0.5 단위 평점
- `timestamp`: UTC 기준 Unix epoch(초)
- `genres`: `|`로 구분된 다중 장르 문자열
